# termux-packages-main
Compiled Termux packages - main repo.

Github limits git repository size to 10 GB.
Run script git-lfs-setup.sh to move largest packages to LFS storage.
This will offload around 4 GB from your repository,
and will not count against your repo size limit.

Script termux-package-sizes.sh will print biggest Termux packages
and their sizes into file package-sizes-main.txt.
